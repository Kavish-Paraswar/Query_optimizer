# Query Optimizer Project

This project is a Query Optimizer implemented in Python. It includes various modules for API handling, dataset management, database utilities, indexing algorithms, and a simple frontend for visualization. The project is designed to efficiently process and optimize queries on large employee datasets.

## Features
- API for query processing
- Dataset management for large CSV files
- Database utility functions
- Indexing algorithms for fast search
- Frontend for user interaction
- Reporting and summary generation

## Installation

1. **Clone the repository:**
   ```powershell
   git clone https://github.com/Kavish-Paraswar/query-optimizer.git
   cd query-optimizer
   ```
2. **Install dependencies:**
   ```powershell
   pip install -r requirements.txt
   ```

## Usage

- Run the main application:
  ```powershell
  python main.py
  ```
- Access the frontend via `frontend/index.html`.
- Reports are generated in the `reports/` folder.

## Project Structure
- `api.py` - API logic
- `dataset.py` - Dataset handling
- `db_util.py` - Database utilities
- `indexing_algos.py` - Indexing algorithms
- `main.py` - Main entry point
- `frontend/` - Frontend files
- `reports/` - Generated reports
